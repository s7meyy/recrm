# رابــح

منصّة لإعداد تقارير تحليلية مفصّلة عن المنشآت التجارية وغير التجارية، مبنيّة على ما ينشره الناس عنها في **خرائط قوقل**: التعليقات والتقييمات وبيانات المنشأة.

مشروع قائم بذاته: HTML + CSS + JavaScript (ES modules) بلا أداة بناء ولا مكتبات خارجية، وكل البيانات محلية في متصفحك.

## التشغيل

```
python3 -m http.server 8080
```
ثم افتح `http://localhost:8080/`. (المتصفح يمنع تحميل ES modules من `file://`، فلا بدّ من خادم ملفات ثابت.)

## المسار داخل المنصّة

| # | المرحلة | ما يحدث |
|---|---|---|
| ١ | **الإدخال** | رابط المنشأة في قوقل مابز + المنطقة والمدينة والتصنيف والحي. |
| ٢ | **البيانات** | بطاقة المنشأة، ولصق التعليقات، والصور. |
| ٣ | **خط التحليل** | ثماني خطوات على أربع مراحل: ٣ نماذج تنظّم ← نموذج يدمج ← ٣ نماذج تحلّل ← نموذج يدمج. |
| ٤ | **التقرير** | صفحة A4 عربية مرقّمة بفهرس وتوزيع نجوم وصور، للطباعة أو الـPDF أو المشاركة. |

## ما يمنع الهلوسة

- **ميثاق مُلزِم** يتصدّر كل رسالة تُرسَل لأي نموذج: لا استنتاج بلا سند.
- **معرّف ثابت لكل تعليق** (`R001`, `R002`…) يُستشهَد به في كل جملة، فيسهل عليك التحقق؛ وهي مُبرَزة بلون مميز في التقرير.
- **الإحصاءات تُحسَب برمجيًّا** في `js/schema.js` وتُسلَّم للنموذج جاهزة، فلا يعيد حسابها ولا يقدّرها.
- **خطوتا الدمج مأمورتان بالحذف لا بالإضافة**، وبالرجوع إلى المصدر عند التعارض، ووسم ما انفرد به مصدر واحد.

## البنية

```
index.html            الواجهة
css/rabih.css         التنسيق
js/
  app.js              منطق الواجهة والتنقّل
  schema.js           عقد البيانات + التحقق + الإحصاءات
  parse.js            تحويل اللصق إلى تعليقات (٣ صيغ)
  prompts.js          مولّد الرسائل الثماني + ترشيح النماذج
  report.js           Markdown ← تقرير A4 مصمَّم
  maps.js             فهم روابط قوقل مابز
  store.js            أرشيف IndexedDB
  data/cities.js      ١٣ منطقة و١٠٥ مدن
  data/categories.js  ١٢ مجموعة و١١٢ تصنيفًا
  data/districts.js   ٥٩٢ حيًّا في ٢٧ مدينة + إضافة يدوية
docs/                 عقد البيانات وخارطة الطريق
tests/e2e.mjs         اختبار شامل في متصفح حقيقي
```

## الاختبار

```
npm i --no-save playwright-core
CHROME_PATH=/path/to/chrome node tests/e2e.mjs
```
