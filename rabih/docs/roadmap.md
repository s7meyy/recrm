# خارطة طريق رابح — وما ينتظر التفعيل

المرحلة ١ **مكتملة وتعمل بلا أي مفتاح**. ما يلي ليس نواقص في البناء، بل مفاتيح مؤجَّلة بقرار،
وكلٌّ منها يُفعَّل وحده دون المساس بما قبله، لأن كل شيء يمرّ عبر [عقد البيانات](data-contract.md).

## ✅ المرحلة ١ — قائمة اليوم

- الواجهة العربية كاملة: المنطقة ← المدينة ← التصنيف ← الحي.
- ١٣ منطقة، ١٠٥ مدن، ٥٩٢ حيًّا في ٢٧ مدينة (مع إضافة يدوية تُحفَظ محليًّا)، ١٢ مجموعة و١١٢ تصنيفًا.
- استخراج يدوي باللصق، بثلاث صيغ مقبولة: الخام من قوقل، الصريحة المرقّمة، وJSON.
- ثماني رسائل جاهزة للنسخ، محصَّنة بميثاق منع الهلوسة.
- تقرير A4 مصمَّم ومرقَّم بفهرس وأشرطة نجوم وصور مضمَّنة.
- أرشيف محلي بشجرة المنطقة/المدينة/التصنيف/الحي، مع تصدير واستيراد.

## ⏳ المرحلة ٢ — مفتاح OpenRouter

**ما يتغيّر:** الخطوات الثماني تصير آلية بلا نسخ ولا لصق.

- المفتاح مجاني الإنشاء بلا بطاقة، وحدّه ~٥٠ طلبًا يوميًّا؛ وبإيداع ١٠ دولارات مرة واحدة يرتفع إلى ~١٠٠٠ طلب يوميًّا.
- خط الأنابيب يستهلك ٨ طلبات لكل تقرير.
- **ما يلزم بناؤه:** موصّل استدعاء، وطابور تنفيذ، وإعادة محاولة، وتنازل تلقائي إلى النموذج البديل عند بلوغ الحدّ — والبدائل مرتّبة أصلًا في `MODEL_PICKS` داخل `js/prompts.js`.
- **ما لا يتغيّر:** نصوص الرسائل نفسها تُرسَل كما هي.

## ⏳ المرحلة ٣ — مفتاح Google Places

**ما يتغيّر:** بطاقة المنشأة والصور وساعات العمل تُملأ آليًّا من الرابط.

- مجاني عمليًّا للاستعمال الفردي (رصيد شهري يغطّي آلاف الطلبات)، لكنه يتطلب حساب Google Cloud وبطاقة للتفعيل.
- **القيد الجوهري:** الواجهة الرسمية تُرجع **خمس مراجعات فقط** لكل مكان. فهي تحلّ مشكلة البيانات الوصفية والصور، لا مشكلة عمق التعليقات.
- **ما يلزم بناؤه:** موصّل `source: 'places'` يُرجع عقد البيانات، ودالة خادمية تخفي المفتاح عن المتصفح.

## ⏳ المرحلة ٤ — مزوّد بيانات وسيط

**ما يتغيّر:** مئات التعليقات تُجلب من الرابط مباشرة، فينتهي اللصق اليدوي.

- مزوّدون مثل Outscraper أو Apify أو SerpApi، بتكلفة ~٠٫٥–٣ دولارات لكل ألف تعليق، وأغلبهم يمنح رصيدًا تجريبيًّا.
- **ما يلزم بناؤه:** موصّل `source: 'provider'` — وهو المسار الوحيد الذي يجعل التقرير يقوم على عيّنة كاملة لا جزئية.

## ⏳ المرحلة ٥ — الإرسال الآلي و PDF على الخادم

- اليوم: الـPDF يُنتَج من المتصفح (طباعة ← حفظ كـPDF)، والإرسال بفتح واتساب/تليقرام/البريد مع نصٍّ مُجهَّز وإرفاق يدوي.
- التفعيل يحتاج: توليد PDF على خادم فيه Chromium، وWhatsApp Cloud API (رقم أعمال + قالب معتمد) أو بوت تليقرام أو خدمة بريد.

## ملاحظة عن الكشط الذاتي

كشط صفحة قوقل مابز برمجيًّا **مخالف لشروط قوقل** ومعرّض للحظر ولانكسار مستمرّ كلما غيّرت قوقل صفحتها.
لذلك لم يُبنَ في المنصّة، والبديل المضمون هو المرحلة ٤.
